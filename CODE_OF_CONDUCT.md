# Code of Conduct

This project follows the Contributor Covenant, version 2.1.

We are committed to a harassment-free, professional collaboration environment. Be respectful, focus technical criticism on the work, and avoid publishing another person's private information.

Instances of abusive, harassing or otherwise unacceptable behavior may be reported privately to the project maintainer.

The full Contributor Covenant 2.1 text is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
